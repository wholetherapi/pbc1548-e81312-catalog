# Ferrous Bloom — fabrication package

Released hardware and firmware sources for the Ferrous Bloom (r4).

Package home: https://github.com/wholetherapi/pbc1548-e81312-catalog/tree/main/packages/ferrous-bloom

## What is in this repository

- `hardware/` — KiCad schematic, panel artwork, fabrication outputs and the
  bill of materials for the shipped revision.
- `firmware/` — Arduino-compatible firmware for the string exciter and reverb send.
- `docs/` — assembly notes, calibration points and the QA checklist.

## Build status

The r4 boards completed the collective's production runs and the files
here correspond to the revision that shipped.  Revisions are tagged in the
repository history; the default branch always reflects the current shipped
revision.
