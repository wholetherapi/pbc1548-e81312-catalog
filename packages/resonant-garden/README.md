# Resonant Garden — fabrication package

Released hardware and firmware sources for the Resonant Garden (r3).

Package home: https://github.com/wholetherapi/pbc1548-e81312-catalog/tree/main/packages/resonant-garden

## What is in this repository

- `hardware/` — KiCad schematic, panel artwork, fabrication outputs and the
  bill of materials for the shipped revision.
- `firmware/` — Arduino-compatible firmware for the piezo driver and damping stage.
- `docs/` — assembly notes, calibration points and the QA checklist.

## Build status

The r3 boards completed the collective's production runs and the files
here correspond to the revision that shipped.  Revisions are tagged in the
repository history; the default branch always reflects the current shipped
revision.
