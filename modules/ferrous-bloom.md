# Ferrous Bloom

Ferrous Bloom is a desktop instrument built around four steel strings driven by
an electromagnetic pickup/exciter pair.  The r4 revision moves the spring tank
behind the string plane and adds a passive damp switch for the lower pair.

The enclosure is a folded aluminium chassis with a walnut cheek panel.  The
design is fully documented: panel cut files, string anchor plates and the
power board are all part of the fabrication package.
